# assets —— 说明

本目录只放**协议结构与错误码等无敏感性数据**，用于照抄/对照。

| 文件 | 内容 |
|---|---|
| `error-codes-and-protocol.md` | 错误码对照表（4/8/1201）、8 组验证矩阵、378 字节请求体结构、响应字段与重写正则、API 路径、域名解析表、hosts 条目、落盘路径 |

## 不包含什么

- **不包含任何真实卡密**（本案例分析的样本无有效卡密，无法通过真实校验）
- **不包含客户端私钥 / 服务器密钥**（AES 密钥在运行时派生，未提取到静态常量）
- **不包含完整的 378 字节密文样本**（时效性 nonce 变化，且无解密价值）

## 想复现怎么办

按 `SKILL.md` 第 5 节的流程：
1. 起 `scripts/mock8880.py` 捕获真实请求（会打印 hex）
2. 用你自己的样本跑，拿到属于你那份的 378 字节
3. 对照本目录的表解读结构

> 提醒：本技能记录的是 **Evo 系**的一种破解思路，**不是所有 DMA 软件都这么干**。
> 先按 `SKILL.md` 第「零」节判定目标的授权形态。
