# Contributing

Thanks for improving Hotspot Radar Workflow Skill.

## Development

Run:

`npm test`

`npm run check`

## Rules

- Do not commit API keys, tokens, raw private data, or provider responses.
- Keep the default output as an owner checklist, not a full script package.
- Mark missing platform metrics explicitly.
- Do not add claims of guaranteed viral performance.
- Keep provider-specific code behind a clear normalization boundary.

## Pull Requests

Please include:

- What changed.
- How it was tested.
- Any provider API assumptions.
- Any safety or compliance impact.
