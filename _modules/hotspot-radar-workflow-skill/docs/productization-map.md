# FIN-SV-004｜热点与对标证据雷达

[English](en/productization-map.md) · [返回中文首页](../README.md)

- 用户任务：从一个主题出发，形成关键词、候选证据和“做 / 观察 / 不做”判断，而不是照抄高播放内容。
- 最低输入：主题、目标受众、目标平台和本轮判断目标。
- 可领取结果：热点证据评分与老板判断表。
- 可验证输出：关键词扩展、证据评分、阻断状态与确定性测试结果。
- 独立边界：Token 或外部证据缺失时必须停止；不承诺抓取成功、爆款、流量或收益。
- 升级路径：进入 PA 的真实样本库、选题批次和周期复盘。
- 需求证据：当前为用户价值假设；仓库验证的是工具行为，不是市场需求。

固定源码版本：`v0.1.4`。该 Tag 不是 GitHub Release。
