# Security And Compliance

## Secrets

- Do not commit API keys.
- Do not paste tokens into README, reports, issues, screenshots, or logs.
- Prefer macOS Keychain through `setup-tikhub-token.mjs`.
- Use `.env` only for temporary local experiments and keep it ignored.

## Platform Content

- Use authorized provider APIs.
- Do not bypass login, access control, rate limits, or platform protections.
- Do not download or redistribute source videos.
- Keep source links and attribution in internal analysis.

## Content Ethics

This project is for topic discovery and original planning.

Do not use it for:

- direct plagiarism
- sentence-level synonym rewriting
- copying unique creator expressions
- unauthorized media reuse
- claims of guaranteed viral performance

## Sensitive Niches

Medical, legal, financial, minors-related, and other sensitive niches need additional human review.
