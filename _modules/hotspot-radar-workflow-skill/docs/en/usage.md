# Usage

[中文主入口](../../README.md) · [English docs](README.md)

1. Enter one broad theme.
2. Review the generated keyword nodes and disable irrelevant terms.
3. Retrieve candidates through the configured provider.
4. Inspect normalized fields and missing-data markers.
5. Review demand signals, fit, transferability, structure, and risk.
6. Use the owner checklist to mark each candidate `do`, `observe`, or `skip`.

The checklist is the end of this Skill's responsibility. Script writing, production, and publishing belong to separate workflows and approvals.
