# FIN-SV-004 — Trend and Benchmark Evidence Radar

[中文](../productization-map.md) · [Back to English README](../../README_EN.md)

- User task: start from a topic and produce keywords, evidence candidates, and a do/watch/skip decision instead of copying high-view content.
- Minimum input: topic, target audience, target platform, and decision objective.
- Claimable handout: trend-evidence scorecard and owner decision sheet.
- Verifiable output: keyword expansion, evidence scores, blocked states, and deterministic test results.
- Independent boundary: stop when a required token or external evidence is unavailable; do not promise retrieval, virality, reach, or revenue.
- Upgrade path: PA real-sample library, topic batches, and periodic review.
- Demand evidence: user value remains a hypothesis; tests prove tool behavior, not market demand.

Fixed source version: `v0.1.4`. This Tag is not a GitHub Release.
